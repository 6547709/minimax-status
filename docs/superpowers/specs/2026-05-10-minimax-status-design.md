# MiniMax Status Dashboard - 设计文档

## 概述

构建一个用于 dashy 监控的服务端程序，提供 HTML 页面展示 MiniMax 套餐使用情况。Go 语言实现，Docker 部署，支持环境变量配置。

## 技术栈

- **语言**: Go 1.21+
- **HTTP 框架**: 标准库 `net/http`
- **模板引擎**: Go 内置 `html/template`
- **部署**: Docker + Docker Compose

## 项目结构

```
minimax-status/
├── main.go              # 程序入口
├── handlers.go          # HTTP 处理器
├── api/
│   └── client.go       # MiniMax API 调用
├── templates/
│   └── index.html      # 页面模板
├── static/
│   └── style.css       # 样式文件
├── Dockerfile          # Docker 镜像构建
├── docker-compose.yml  # 容器编排
├── .env.example        # 环境变量示例
└── README.md
```

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `MINIMAX_API_KEY` | MiniMax API 密钥 | 必填 |
| `MINIMAX_API_URL` | API 服务器地址 | `https://www.minimaxi.com` |
| `PORT` | HTTP 监听端口 | `8080` |

## 页面功能

- **刷新机制**: 页面加载时请求数据，用户刷新页面获取最新数据
- **无认证**: 直接访问 `/` 即可查看
- **错误处理**: API 错误时显示友好提示
- **响应式**: 嵌入 dashy 组件时宽度自适应

## API 调用

与 Node.js 实现相同：
- `GET https://www.minimaxi.com/v1/token_plan/remains` - 获取使用量
- `GET https://www.minimaxi.com/account/amount` - 获取 Token 消耗统计

## UI 设计

### 主题支持

使用 CSS 变量 + `prefers-color-scheme` media query 自动适配浏览器主题。

**浅色模式 (Light)**
- 背景: `#f8fafc`
- 卡片背景: `#ffffff`
- 主色调: `#6366f1`
- 文字: `#1e293b`
- 边框: `#e2e8f0`

**深色模式 (Dark)**
- 背景: `#0f172a`
- 卡片背景: `#1e293b`
- 主色调: `#818cf8`
- 文字: `#f1f5f9`
- 边框: `#334155`
